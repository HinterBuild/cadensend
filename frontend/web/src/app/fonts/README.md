# Bundled fonts

These unmodified Latin WOFF2 subsets were previously served by Google Fonts through `next/font/google`. They are now loaded with `next/font/local` so builds and page views do not need Google Fonts network access. Characters outside the subsets use the browser's fallback font.

- **Geist**: [Vercel's font project](https://github.com/vercel/geist-font), license in `Geist-OFL.txt`.
- **Newsreader**: [Production Type's font project](https://github.com/productiontype/Newsreader), license in `Newsreader-OFL.txt`.

Keep the font binaries and their licenses together when redistributing this application.
